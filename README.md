### Manuscript
This code repository is associated with the following manuscript:

Villwock, S.S., Gómez, K.M., Fish, T. et al. Gene-metabolite networks reveal physiological trade-offs but not transcriptional co-regulation between carotenoid and dry matter accumulation in cassava (_Manihot esculenta_) roots. BMC Plant Biol (2026). https://doi.org/10.1186/s12870-026-10012-y

### Raw data
Raw RNA sequencing data is publicly available at NCBI Sequencing Read Archive (SRA) under BioProject ID PRJNA1258369 (http://www.ncbi.nlm.nih.gov/bioproject/1258369). 

### Germplasm 
Cassava accessions used in this study were contributed to the National Clonal Germplasm Repository at the USDA Subtropical Horticulture Research Station, Miami, Florida.
